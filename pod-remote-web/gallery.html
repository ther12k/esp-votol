ARMED

DISARMED

OFFLINE

4. ARM Confirmation
SECURITY GATE

5. Configuration
CONFIG
"Read Config from Pod" card-button, then icon-badged cards: SECURITY PIN (amber lock), SPEED CALIBRATION (teal gauge), PHYSICAL FOBS (green radar) + red destructive clear, VOTOL BRIDGE BT LINK (blue). APPEARANCE card (dark-theme switch) sits below the fold.
6. Device Pairing
PAIRING
Big amber Scan QR Code pill (camera icon, dark text) — scans the pod's SYS → SET screen; divider then monospace 32-hex manual key entry, green Save Key + red Forget.

📐 v3.0 Design Tokens (mirror of the APK resources)

  • Theme system: DayNight resource aliases — values/colors.xml (light) vs values-night/colors.xml (dark); switched live via AppCompatDelegate.setDefaultNightMode, persisted in prefs (darkTheme, default true).
  • Brand: amber fill #F5B301 (logo badge, scan pill, nav indicator); amber text #FFC93C dark / #B45309 light.
  • State colors: green #22E06A/#0E9F5B, red #E5484D/#D93A3F, cyan battery #3EC9F0/#0E8FB8; hero tints armed #2A1115/#FBEBEC, disarmed #10241C/#E7F8EF, offline #161B27/#EDF1F6.
  • Surfaces: bg #0A0F14/#F2F5F8, card #131A24/#FFFFFF, border #2A3440/#DFE5EC.
  • Primary CTA: 84dp, radius 24dp — icon + label(19sp)/sub(12sp) + 40dp arrow chip; green DISARM / outlined-red ARM / neutral Connect.
  • Config badges: 34dp rounded-12 tinted squares with amber/teal/green/blue strokes and matching icons.
  • Bottom nav: floating pill (radius 28, margins 12/10, 64dp) with amber active indicator.
  • URL states: /index.html?state=armed|disarmed|offline&tab=control|config|pairing&theme=dark|light&frame=raw&modal=arm
