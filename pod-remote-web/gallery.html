📐 v4.0 tokens & components (mirror of the APK resources)

  • Palette (dark): bg #070B0F, surface #0D141A, elevated #121B22, border #2B3A43, text #F4F7F8/#93A4B2.
  • Signals: amber #F7A915 (brand/nav/pairing CTA), jade #40F0B6 + green #21D99B (disarmed/safe), red #FF4D57 (armed/panic/destructive), cyan #59E6FF (battery), blue #55A7FF, violet #7B7CFF.
  • Hero dial: custom HeroDialView — 60-tick ring, 240° SweepGradient arc, radial glow, center disc; color driven by state (jade/red/slate).
  • Glows: CTA halos (layered translucent shapes on Android / box-shadow on web) — jadeGlow/amberGlow/redGlow per kit effects.
  • Icons: kit stroke SVGs (1.8 stroke, currentColor) converted to Android vectors; tinted at usage site. Mono labels via JetBrains Mono/monospace.
  • Theme system: DayNight aliases — light palette derived from the same hues; persisted pref, header sun/moon + Config → Appearance switch.
  • URL states: /index.html?state=armed|disarmed|offline&tab=control|config|pairing&theme=dark|light&frame=raw&modal=arm
