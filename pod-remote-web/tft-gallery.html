Double-tap wake → padlock title + PIN entry boxes (dot per digit, cyan ring on the active box) + edge-to-edge 4×3 keypad, 76×54 px keys: digits, backspace, green OK. Wrong PIN locks 15 s after 3 tries.

📐 TFT Design Constraints for the Designer Agent

  • Panel: 240×320 portrait ILI9341 over 8-bit parallel; no anti-aliasing, no custom fonts — classic 5×7 bitmap font, sizes 1–8 (char cell 6×8 px × size).
  • Kit v3 palette (Oct 2026 mockups): bg #08111D, card #121C2C, border #38485C, text #E6EEF7, muted #86A1BF, cyan #00D0FF, green #00FF80, red #FF3B3B, amber #FFC107; value/accent user-pickable from 6 swatches (cyan default).
  • Layout grid: header 0–28 (title left · status dot + battery gauge right) over a 1-px divider at y29, sub-tabs 32–68 (SYS only), content 30–277, tab bar 278–318 (3 × 80 px tabs: TELE / LOCK / SYS, active = accent fill).
  • Backlight hardwired to 3.3 V — "screen off" is either pure black (disarmed) or the static armed prohibition sign (ring + X, far-distance legible); standby must be a single still frame.
  • Touch: resistive film shared with the LCD bus — targets must be ≥ ~60 px for gloved fingers; PIN keypad keys are 76×54 px.
  • State machine: fob near → disarmed; fob away 30 s → armed (+chirp); riding (rpm ≥ 50 for 2 s) locks TELE to RIDE pane; phone/PIN disarm is sticky until explicit ARM.
