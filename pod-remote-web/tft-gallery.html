11. ARMED standby 🚫
SECURITY
Armed idle: full-screen bold prohibited symbol (14-px ring + 34-px X), readable from a distance, battery voltage, double-tap hint. Static — no animation.
12. PIN gate
SECURITY
Double-tap wake → edge-to-edge 4×3 keypad, 76×54 px keys. Green OK, yellow C. Wrong PIN locks 15 s after 3 tries.
13. ARM confirmation
SECURITY
Full-screen YES/NO gate so a stray tap can never arm. NO (green) first, YES, ARM (red) below — timed out after 10 s.
14. ARM animation 🔒

5-frame closing padlock (shackle seats, right leg plugs in) + zooming "ARMED" text, then the standby emblem.

17. WiFi/OTA setup window
BOOT

📐 TFT Design Constraints for the Designer Agent

  • Panel: 240×320 portrait ILI9341 over 8-bit parallel; no anti-aliasing, no custom fonts — classic 5×7 bitmap font, sizes 1–5 (char cell 6×8 px × size).
  • Fixed palette: bg #0A101A, widget #121A28, text #DEE6F0, dim #6E7C8C, red #FF3C32, green #00FF78, yellow #FFC800; the user can pick value/accent from 6 swatches (cyan default #00C8FF).
  • Layout grid: header 0–26, sub-tabs 28–68 (SYS only), content 27–277, tab bar 278–318 (3 × 80 px tabs: TELE / LOCK / SYS).
  • Backlight hardwired to 3.3 V — "screen off" is either pure black (disarmed) or the static armed emblem; standby must be a single still frame.
  • Touch: resistive film shared with the LCD bus — targets must be ≥ ~60 px for gloved fingers; PIN keypad keys are 76×54 px.
  • State machine: fob near → disarmed; fob away 30 s → armed (+chirp); riding (rpm ≥ 50 for 2 s) locks TELE to RIDE pane; phone/PIN disarm is sticky until explicit ARM.
